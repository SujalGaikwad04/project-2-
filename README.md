# 🎬 Editkaro.in – Video Editing & Social Media Marketing Agency Website

A modern, responsive, and professional portfolio website developed for **Editkaro.in**, a video editing and social media marketing agency. The website showcases the company's services, portfolio, and contact information while providing a seamless user experience across desktop, tablet, and mobile devices.

# 📖 Project Overview

The objective of this project was to build a professional agency website that effectively showcases Editkaro.in's video editing services and portfolio. The website focuses on clean UI/UX, responsive design, smooth navigation, and interactive elements while fulfilling all internship project requirements.

In addition to the frontend development, the project includes Google Apps Script integration that automatically stores Email Subscription and Contact Form submissions in Google Sheets.
